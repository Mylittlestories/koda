# 📝 Koda Beta — Tester Feedback Form

> © 2026 DRVsoft · A simple 3-question form to pair with the invite.
> Keep it short — 3 questions, under 2 minutes, works for kids **and** adults.

---

## How to set it up (Google Forms)

1. Open **forms.google.com** → **Blank form**.
2. Title: **Koda Beta — Tell us what you think!** · description: "Thanks for testing Koda! 3 quick questions, takes 2 minutes. You're helping make learning tech kids actually love. 🦊"
3. Create the 3 questions below (copy-paste the text).
4. Set responses → collect emails: *off* (keep it anonymous — testers share more).
5. Settings → "Limit to 1 response" — on.
6. Get the link from **Send** and paste it into your invite (replace `{FEEDBACK_URL}`).

---

## The 3 questions

### Q1 · What was the MOST fun thing you did in Koda?
- ( ) 🎮 Coding with blocks
- ( ) 🗺️ Exploring the adventure (Forest / Caverns / Sky Temple)
- ( ) 🎨 Editing photos
- ( ) 🎬 Making a movie
- ( ) 🧠 Learning lessons / quizzes
- ( ) Something else: ______

### Q2 · What confused you or felt broken?
- ( ) Nothing — it all worked! 😄
- ( ) The adventure puzzles
- ( ) The coding blocks
- ( ) Saving / exporting my work
- ( ) The sound or music
- ( ) Something else: ______

### Q3 · If you could change ONE thing about Koda, what would it be?
(Long answer — free text)

## Optional extra (only if you want more depth)

### Q4 · Who tested it? *(helps us interpret the answers)*
- ( ) Kid (7–10)
- ( ) Kid (11–13)
- ( ) Parent/guardian
- ( ) Teacher/educator
- ( ) Developer/hobbyist

> Keep Q4 optional — some testers prefer not to say, and that's fine.

---

## Tester feedback notes (how to read the answers)

- **Q1 fun** → tells you what to double-down on. If "adventure" wins, deepen the regions.
- **Q2 confusion** → your bug/UX backlog. Anything named by 2+ testers goes to the top.
- **Q3 one thing** → the single best product signal you'll get. Make a shortlist and pick one per cycle.
- If a tester pastes a **bug report** (Settings → 🐞), file it as a GitHub Issue immediately.
